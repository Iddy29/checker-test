================================================================================
TROUBLESHOOTING
================================================================================

Problem: Bot won't start
Solution: 
   - Check config.json exists: ls -la /opt/telegram-bot/config.json
   - Test manually: cd /opt/telegram-bot && python3 bot.py
   - Check logs: journalctl -u telegram-bot -f

Problem: Permission denied
Solution:
   chmod 755 /opt/telegram-bot/*.sh
   chmod 600 /opt/telegram-bot/config.json

Problem: Missing dependencies
Solution:
   cd /opt/telegram-bot
   pip3 install -r requirements.txt

Problem: Bot crashes on startup
Solution:
   - Check Python version: python3 --version (need 3.8+)
   - Check if port 22 is open on firewall
   - Verify config.json has correct values
