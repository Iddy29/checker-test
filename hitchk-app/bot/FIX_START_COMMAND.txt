================================================================================
STEP 3: Start the Bot Manually (to see errors)
================================================================================

On VPS, navigate to bot directory:
    cd /opt/telegram-bot
    (or wherever bot.py is located)

Stop any running bot:
    pkill -f "python.*bot.py"

Run bot in foreground to see errors:
    python3 bot.py

WATCH FOR ERRORS! Common issues:

ERROR: "ModuleNotFoundError: No module named 'aiofiles'"
FIX: pip3 install aiofiles aiohttp telethon requests

ERROR: "Your API ID or Hash cannot be empty"
FIX: config.json is not being read. Check if config.json exists:
    ls -la config.json
    
    If missing, create it or copy from backup.

ERROR: "Unauthorized" or "Invalid bot token"
FIX: Your bot token in config.json is wrong. Update it:
    nano config.json
    (Update TELEGRAM_BOT_TOKEN, then Ctrl+X, Y, Enter)

ERROR: "Address already in use" or "Session file locked"
FIX: Delete old session file:
    rm cc_bot.session*
    Then restart bot.

If bot starts successfully, you'll see:
    "Bot started successfully as @YourBotUsername"
    "Bot is now running..."

Now press Ctrl+C to stop it, then run in background:
    nohup python3 bot.py > bot.log 2>&1 &

Test in Telegram: Send /start to your bot.
